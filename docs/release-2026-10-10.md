# Shared-loader template update — October 10, 2026

This update uses one shared `loader.js` for CYBEXO Web CMP. The template establishes native Google consent defaults before loading or resuming the engine, and publishes validated choices through the native GTM consent APIs. Customers do not select an engine release.

For TCF sites with consumers running before GTM, use the short synchronous shared-loader setup in [installation guidance](installation.md#tcf-page-setup). Replace the previous separate bootstrap setup when adopting this release; keep one installation and the same actual CYB App ID. Compatible platform connectors must manage their own host declaration and avoid a second loader.

The scoped GTM runtime audit passed against Web CMP 1.5.48. This is engineering verification, not Google or IAB certification or a guarantee for every customer container.

## Adopt the update

1. Check the latest entry in [metadata.yaml](../metadata.yaml) against the revision offered by **Cybexo CMP** in the Community Template Gallery.
2. Review and accept the update in your workspace. Preserve your App ID, native consent settings and **Consent Initialization – All Pages** trigger.
3. Preview fresh visits, saved choices, accept/reject, mixed choices and withdrawal in Tag Assistant, including another open tab.
4. Publish the tested container.

[Google states that Gallery updates typically appear within two to three days](https://developers.google.com/tag-platform/tag-manager/templates/gallery#update_your_template) after publication. A repository push does not prove Gallery indexing and does not automatically update published customer containers. If the offered revision is older, wait for the matching update before adopting this installation contract.
